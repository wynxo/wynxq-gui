# Glass and chrome interface refresh

The native Qt Quick interface now uses a cooler graphite palette, a centered
home layout and a reflective edition of the existing arcs-and-core mark.
Buttons, mode selection, the fresh-task composer and the welcome panel share
the same glass edge and highlight treatment. Conversation surfaces remain
opaque and readable.

The sculpture is a bundled vector asset, generated by
`scripts/build_chrome_mark.py`. Its compressed SVG is about 149 KB. Qt caches
its rasterization; only pointer movement changes its rotation. Reduced Motion
disables this feedback. No idle animation or external asset service is needed.
At short window heights the sculpture hides so typing keeps priority.

The shared glass surface only instantiates a capture/blur pipeline when an
explicit, separate backdrop is supplied and a hardware renderer is available.
The backdrop mask follows rounded corners. The software renderer uses the
opaque material fallback; this update does not depend on compositor blur.

The welcome guide now supports Back, optional project selection and a bounded,
scrollable explanation area. Its entrance obeys Reduced Motion. Small marks
also repaint correctly after a resize. Text buttons no longer grow on hover.
